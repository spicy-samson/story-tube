# Docs

This folder holds planning docs for YouTube Story Maker. The repo follows a folderized `README.md` convention: each documentation area starts with a `README.md` that explains what belongs there and links to the active working documents.

## Index

| Folder | Read This For |
|---|---|
| [proposal](./proposal/README.md) | Why this project exists, what v1 includes, and what is intentionally out of scope |
| [milestones](./milestones/README.md) | Build timeline, checkpoints, and success criteria |
| [product](./product/README.md) | User, core flow, MVP requirements, names, monetization, and roadmap |
| [architecture](./architecture/README.md) | PWA stack, system shape, data flow, export strategy, and technical risks |
| [decisions](./decisions/README.md) | Decision records made during planning and implementation |
| [learning](./learning/README.md) | Runtime explanations for implemented features and code ownership |

## Documentation Rule

When a new major area appears, create a folder and put its overview in that folder's `README.md`. Add extra files only when a topic grows large enough to deserve its own page.
